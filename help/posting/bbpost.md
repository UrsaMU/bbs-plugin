+BBPOST

Post a message to a BBS board with **+bbpost**.

SYNTAX
  +bbpost[/ic|/ooc] [<#>/<subject>[=<body>]]

SWITCHES
  /ic    Tag the post as In-Character.
  /ooc   Tag the post as Out-of-Character.

EXAMPLES
  +bbpost 2/Big News=The war is over.  Quick-post to board 2.
  +bbpost/ic 2/Scene Recap             Open an IC draft on board 2.
  +bbpost                              Submit your current draft.

SEE ALSO: +help bb, +help bbproof, +help bbtoss, +help bbreply
