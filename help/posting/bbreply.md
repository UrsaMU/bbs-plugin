+BBREPLY

Reply to a BBS post with **+bbreply**.

SYNTAX
  +bbreply[/ic|/ooc] <#>/<post>[=<text>]

SWITCHES
  /ic    Tag the reply as In-Character.
  /ooc   Tag the reply as Out-of-Character.

EXAMPLES
  +bbreply 2/3=Great post!    Quick-reply to board 2, post 3.
  +bbreply/ic 2/3             Start an IC reply draft for post 3.

SEE ALSO: +help bbpost, +help bb, +help bbwatch
