+BBREAD

Read BBS boards or posts with **+bbread**.

SYNTAX
  +bbread [<#>[/<posts>]]

EXAMPLES
  +bbread             Show all boards grouped by category.
  +bbread 2           List posts on board 2.
  +bbread 2/3         Read post 3 on board 2.
  +bbread 2/3*        Read post 3 and all its replies.
  +bbread 2/3.1       Read reply 1 on post 3 of board 2.
  +bbread 2/u         Read all unread messages on board 2.
  +bbread 2/1-5       Read posts 1 through 5 on board 2.

SEE ALSO: +help bbnext, +help bbcatchup, +help bbunread
