+BBCATCHUP

Mark one or all BBS boards as fully read with **+bbcatchup**.

SYNTAX
  +bbcatchup [<#>|all]

EXAMPLES
  +bbcatchup 2    Mark board 2 as fully read.
  +bbcatchup all  Mark all boards as fully read.
  +bbcatchup      Same as +bbcatchup all.

SEE ALSO: +help bbread, +help bbnext, +help bbunread
