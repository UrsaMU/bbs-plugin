+BBCATEGORY

Set the display category for a BBS board with **+bbcategory**. Staff only.

SYNTAX
  +bbcategory <#>=<category>

EXAMPLES
  +bbcategory 2=Roleplay    Move board 2 into the "Roleplay" category.
  +bbcategory 2=General     Reset board 2 to the default category.

SEE ALSO: +help bbnewgroup, +help bbconfig
