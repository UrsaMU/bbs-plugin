+BBNEWGROUP

Create a new BBS board with **+bbnewgroup**. Staff only.

SYNTAX
  +bbnewgroup <title>[=<category>]

EXAMPLES
  +bbnewgroup Announcements          Create board in "General" category.
  +bbnewgroup IC Events=Roleplay     Create board in the "Roleplay" category.

SEE ALSO: +help bbcleargroup, +help bbcategory, +help bbconfig
