+BBWEBHOOK

Set or clear a Discord webhook URL for a BBS board with **+bbwebhook**.

SYNTAX
  +bbwebhook <#>=<url>

EXAMPLES
  +bbwebhook 2=https://discord.com/api/webhooks/...    Set webhook.
  +bbwebhook 2=                                        Clear webhook.

SEE ALSO: +help bbnewgroup, +help bbconfig
